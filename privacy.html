Privacy Policy

Last updated: October 25, 2026

TruthBeOld Uploader is a private tool used only by the owner of the connected YouTube channels.

Data accessed: With the owner's permission, the tool uses the YouTube Data API to upload videos and set their titles, descriptions and tags on the owner's own channels.

Storage: The access token is stored only on the owner's private server. No data is sold, shared with third parties or used for advertising.

Revoking access: Access can be removed at any time at https://myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
